# edamhamza.dev

Personal portfolio built with Next.js 16, Tailwind CSS v4, and Framer Motion.

## Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Styling:** Tailwind CSS v4 with class-based dark mode
- **Animations:** Framer Motion
- **Fonts:** Instrument Serif, DM Sans, JetBrains Mono
- **Email:** Resend
- **Deployment:** Vercel

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

```
src/
  app/           # Next.js app router pages and API routes
  components/    # UI components and sections
  lib/           # Data, types, and utilities
public/          # Static assets (images, resume)
```
